# Interactive Python Chess

A lightweight, interactive 2D chess board built entirely from scratch using Python's built-in `tkinter` library.

Currently, the project functions as a sandbox board: players can click and move pieces freely across the board, take turns, and capture pieces.


## Setup & Installation

1. Ensure you have Python installed on your computer.
2. Clone or download this repository.
3. Make sure the folder containing the chess piece images (`pieces-basic-png`) is located in the exact same directory as the `chess.py` script.
4. Run the game from your terminal:
```bash
python chess.py

```


## How to Play

1. The game starts with White's turn.
2. **Click once** on the piece you want to move (it will be highlighted with a red square).
3. **Click again** on an empty square or an opponent's piece to complete the move.
4. If you change your mind after selecting a piece, simply click the exact same piece again to deselect it.
